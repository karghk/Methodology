An independent human operator must perform a preselected observable event without communicating its timing or occurrence to the AI.

## Prohibited substitutions

The following do not satisfy V3:

- an AI-generated repository mutation;
- an AI-requested scheduled event;
- a fabricated event fixture;
- a retrospective reconstruction from chat history;
- an AI-authored statement that an event occurred;
- an event whose timing was disclosed to the AI beforehand.

## Completion evidence

The V3 trial may proceed only when there is an independently controlled event and an externally inspectable IOEL record captured before the AI is informed.
