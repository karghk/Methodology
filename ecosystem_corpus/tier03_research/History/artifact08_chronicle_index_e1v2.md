PURPOSE

The Chronicle Index provides the organized reference system for the Companion Chronicle.

Its purpose is to preserve:

- historical locations
- transition relationships
- chronological ordering
- conceptual evolution paths
- recoverable historical context

The Chronicle Index does not create history.

It organizes access to preserved history.
